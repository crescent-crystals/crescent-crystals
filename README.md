Crescent Crystals: A Lunar Adeventure

Requirements:
    - Python installed on the machine and available in the command line.
    - Pygame library installed.
    - All files from the repository (i.e. fonts, sounds, etc.) downloaded on your machine.

Guide on installing Pygame:
    python -m pip install pygame-ce

If that gives an error, use this:
    python3 -m pip install --upgrade pip
    &&
    python -m pip install pygame-ce
    
How to play:
    1. Press keys "Esc" or "Q" quit the game
    2. Click the left button to select the left option.
    3. Click the right button to select the right option.

Aim of the game:
    - Survive against the harsh conditions of the lunar surface.
    - Make the right choices in order to collect a maximum of 5 Crescent Crystals.
    - Choose even the craziest path and explore the Moon in your own way!
